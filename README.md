# Aplikacja do oceny dostępności cyfrowej

Aplikacja wspierająca analizę zgodności stron internetowych z wymaganiami WCAG oraz Ustawą o dostępności cyfrowej.

## Technologie

- C#
- ASP.NET Core MVC
- Entity Framework
- SQLite

## Funkcjonalności

- analiza dostępności stron internetowych
- generowanie raportów
- przechowywanie wyników analizy dla zalogowanych użytkowników
- logowanie i rejestracja użytkowników
- przegląd historii wykonanych analiz
